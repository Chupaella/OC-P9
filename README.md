# 724 Events – Application événementielle avec React

---

## Contexte
724 Events est un projet réalisé dans le cadre de la formation Intégrateur Web OpenClassrooms..  
L’objectif était de développer une application React complète affichant des événements dynamiques, avec gestion de l’état global, du chargement des données et des erreurs..

---

## Objectifs pédagogiques
- Structurer une application React complète
- Gérer des données via un contexte global
- Implémenter des états de chargement et d’erreur
- Créer des composants réutilisables
- Assurer la robustesse et la maintenabilité de l’application

---

## Technologies utilisées
- HTML5
- CSS3
- JavaScript
- React
- Context API

---

## Fonctionnalités principales
- Affichage dynamique des événements
- Mise en avant du dernier événement
- Filtrage et pagination des événements
- Gestion des états loading et error
- Interface fluide et responsive

---

## Contraintes du projet
- Utilisation de React sans framework externe
- Gestion des données via Context API
- Respect des maquettes fournies
- Gestion explicite des erreurs
- Compatibilité avec les navigateurs modernes

---

## Choix techniques
- Centralisation des données avec Context API
- Séparation claire entre composants de présentation et de logique
- Gestion globale des états loading et error
- Structuration de l’application pour faciliter l’évolution

---

## Installation et lancement
Aucune installation particulière n’est nécessaire..

1. Cloner le dépôt
2. Installer les dépendances avec `npm install`
3. Lancer l’application avec `npm start`

---

## Points forts
- Architecture React claire et cohérente
- Gestion robuste des données et des états
- Composants réutilisables et lisibles
- Application stable et maintenable
- Bonne séparation des responsabilités
